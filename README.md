
# C++ Employee Record Manager

A C++ console application that reads employee records from a text file, stores them in a custom linked list, and displays employee information.

## Features
- Reads employee information from `Employee_File.txt`
- Stores employee ID, first and last name, phone number, email address, and salary
- Implements a custom singly linked list using pointers
- Displays employee records in the console
- Releases dynamically allocated memory after use

## Technologies and Concepts
- C++
- Object-oriented programming
- Classes and constructors
- Linked lists and pointers
- File input/output (`ifstream`)
- Dynamic memory management

## How to Run
1. Download or clone this repository.
2. Make sure `Employee_File.txt` is in the same working directory where you run the program.
3. Compile the C++ source file using a C++ compiler, such as `g++`.
4. Run the compiled program to display the employee records.

## Project Purpose
This project demonstrates foundational C++ programming skills, including file handling, object-oriented design, linked data structures, and manual memory management.
